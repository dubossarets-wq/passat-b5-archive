# Архив Passat B5 1.8 20V (ARG)

Личный веб-архив по одной машине: журнал работ, регламент с напоминаниями, документы
с поиском по тексту PDF, запчасти с номерами VAG, справочник кодов ошибок, база знаний,
ссылки. Один пользователь, всё хранится у вас на компьютере. Оформление — на дизайн-системе
Radix UI (Radix Themes: токены и цвета), светлая и тёмная тема переключаются сами.

## Запуск

Нужны Node.js 22.13 или новее (https://nodejs.org) и, если берёте проект из git, сам Git.

```
git clone <адрес репозитория> Passat-B5-Archive
cd Passat-B5-Archive
start.bat
```

Или, если проект уже на диске, просто дважды щёлкните **`start.bat`**. При первом запуске он
сам поставит зависимости (нужен интернет, около минуты) и загрузит черновики справочников.

1. В окне появятся адреса:
   - `http://localhost:8080` — на этом компьютере;
   - `http://192.168.x.x:8080` — с телефона, если он в той же сети Wi-Fi.
2. Вход без пароля: архив сразу открыт. Если не хотите, чтобы он был открыт всем в вашей
   сети Wi-Fi, включите пароль: Меню → Настройки → Пароль.
3. Windows при первом запуске спросит про доступ к сети. Разрешите для частной сети,
   иначе телефон не увидит архив.

Обновить проект из git: `git pull`, затем снова `start.bat`. Ваши данные (`data\`) в git не
входят и при обновлении не затрагиваются.

Окно `start.bat` не закрывайте, пока работаете: закроете — архив остановится.
Другой порт: в командной строке в папке проекта `set PORT=8081 && .\start.bat`
(в консоли нужен именно `.\start.bat`: просто `start.bat` cmd понимает как свою команду `start`).

С телефона удобно добавить страницу на главный экран браузера. Кнопка «Быстрая запись»
открывает камеру телефона: запись с фото — это пробег, что сделано и снимок.
Камера работает и по обычному `http://` в домашней сети.

## Где лежат данные

Всё в папке `data\` внутри проекта (в git она не попадает):

| Путь | Что там |
|---|---|
| `data\archive.db` | база SQLite: журнал, документы, коды, статьи, настройки |
| `data\files\` | оригиналы загруженных файлов, фото, PDF |
| `data\thumbs\` | превью фото (создаются заново, копировать не нужно) |
| `data\backups\` | автокопии базы и папки `before-restore-…` |

Что и откуда было взято при создании справочников, видно в папке `seed\`.

## Резервная копия

- **Из программы:** Меню → «Настройки, копия и восстановление» → «Скачать весь архив (ZIP)».
  В ZIP лежат база и все файлы, плюс опись с контрольными суммами.
- **Из командной строки:** `backup.bat` (или `backup.bat D:\Копии\passat.zip`).
- **Автоматически:** при каждом запуске в `data\backups\` сохраняется копия базы
  (хранятся последние 10). Это копия только базы, без файлов. Для полной защиты
  делайте ZIP и храните его не только на этом компьютере.

## Восстановление

- **Из программы:** Настройки → «Восстановление из ZIP».
- **Из командной строки:** остановите архив и запустите `restore.bat путь\к\архиву.zip`.
  Для очень больших архивов лучше этот способ.

Перед заменой архив проверяется (опись, контрольные суммы, целостность базы,
посторонние пути). Текущие данные не удаляются, а переносятся в
`data\backups\before-restore-<время>\`. Если что-то пошло не так, старые данные
возвращаются на место. Если в архиве был включён пароль, после восстановления нужно войти им заново.

Git хранит только программу и черновики справочников. Ваши данные (`data\`) — отдельно,
их защищает ZIP-копия.

## Как считаются напоминания

Для каждой позиции регламента берётся **последняя запись журнала**, где эта позиция
отмечена галочкой «Закрывает позиции регламента».

- Срок по пробегу: пробег той записи + интервал в км.
- Срок по дате: дата записи + интервал в месяцах (31 января + 1 месяц = конец февраля).
- Статус определяет худший из двух сроков.
- **Просрочено** — остаток меньше нуля. **Скоро** — остаток от нуля до порога
  включительно (по умолчанию 1000 км или 30 дней, меняется в настройках).
  **В норме** — остальное.
- «Нет данных» — в журнале нет записи о замене. «Интервал не задан» — вы не указали интервал.

Текущий пробег — последнее показание: его можно обновить на главной или указать в записи журнала.

**Интервалы в регламенте — черновики со статусом «не проверено».** Их нашли в открытых
источниках (ссылка у каждой позиции), официального графика ТО VW в открытом доступе нет.
Сверьте их со своими документами и поправьте. Для ремня ГРМ это особенно важно.

## Критичные параметры

Моменты затяжки, установка и натяжение ГРМ, допуски и объёмы масла и жидкостей,
регулировки. Приложение их **не знает и не подставляет**. В Меню → «Критичные параметры»
значение сохраняется только вместе с источником: документом из архива (например,
вашей распечаткой из erWin) или официальной ссылкой. Пока источника нет, везде в
статьях и кодах показывается «уточнить по официальной документации».
Тест следит, чтобы в черновиках не было таких цифр.

## Статусы и источники

У справочных материалов есть статус **«не проверено»** или **«проверено мной»** (кнопка на странице)
и источники: ссылка, дата, к какому мотору относится (ARG, ADR/APT, Passat B5, Audi A4 B5, OBD-II общее).
Всё, что загружено из черновиков, имеет статус «не проверено». С форумов и блогов взяты только
ссылки и пересказ своими словами.

Не копируются платные базы (Autodata, HaynesPro, Alldata, Mitchell, ELSA/erWin).
Доступ к erWin оформляется на сайте производителя; в архив вы кладёте свои распечатки как документы.

## Поиск

Общий поиск ищет по журналу, документам (включая текст внутри PDF), статьям, кодам и запчастям.
Слова находятся в разных формах (масло, масла, маслом), номера деталей — с пробелами и без.
Для сканов без текстового слоя текст не извлекается (распознавание — этап 2),
такие документы ищутся только по названию и тегам.

## Безопасность

- **По умолчанию пароля нет**: любой, кто подключён к вашей сети Wi-Fi и знает адрес, может
  открыть архив, в том числе VIN и чеки. Пароль включается и отключается в Настройках.
- Если пароль включён: он хранится как scrypt-хеш, вход ограничивает частоту неверных попыток,
  файлы отдаются только после входа.
- Запросы с чужих сайтов отклоняются всегда.
- **В домашней сети соединение по `http://`, не шифруется.** Не используйте пароль,
  который у вас где-то ещё. HTTPS появится при размещении на сервере (этап 3). Перед выкладкой
  в интернет пароль обязателен.
- Приложение само никуда ничего не отправляет. Исключение: кнопка «Проверить ссылки»
  открывает адреса из вашего списка ссылок, ничего от вас в них не передавая.
- Известное замечание `npm audit` (minimatch в archiver) касается функций поиска
  файлов по маске, которых это приложение не использует.

## Проверка ссылок

В программе: Меню → Ссылки → «Проверить, что ссылки открываются».
Из командной строки: `npm run check-links` (раздел «Ссылки») или
`node src/cli/check-links.js --all` (все ссылки из кодов, статей, регламента, деталей).
Часть сайтов (в основном drive2.ru) не отвечает автоматическим запросам, такие ссылки
помечаются «открыть вручную».

## Тесты

`npm test` (нужны установленные зависимости). Проверяются: расчёт напоминаний,
поиск (словоформы, коды, номера), экспорт и восстановление ZIP (в том числе
вредные и повреждённые архивы), PDF, вход и защита, правила для черновиков.

## Структура

```
start.bat, backup.bat, restore.bat   запуск, копия, восстановление
src\       сервер и логика (routes — страницы, lib — расчёты, поиск, архив)
public\    стили, скрипты, просмотрщик PDF, токены Radix (radix\, лицензия MIT)
seed\      черновики: коды, статьи, ссылки, регламент, детали, параметры
tests\     тесты
data\      ваши данные (создаётся при первом запуске)
```

## Что дальше

Этап 2 (по вашему решению): импорт отчёта Auto-Scan из VCDS, диагностика через ELM327
из браузера, распознавание текста в сканах. Этап 3: размещение на сервере с HTTPS
и ИИ-помощник по архиву.

Ограничения этой машины для будущей диагностики: по общему OBD-II отвечает только блок двигателя
(и не гарантированно, если машина старше 2001 года); ABS, подушки и блок комфорта работают
по протоколу KW1281, который ELM327 не поддерживает, для них остаётся импорт из VCDS.
