# Справочник Passat B5 1.8 20V (ARG)

Справочник по одной машине: VW Passat B5, кузов 3B, мотор 1.8 20V ARG.
Коды ошибок, статьи о типовых проблемах и ремонте, ссылки на электросхемы, номера
запчастей VAG с аналогами, регламент ТО, полезные ссылки. Ничего заполнять не нужно:
есть только строка поиска.

**Сайт:** https://dubossarets-wq.github.io/passat-b5-archive/ — открывается с компьютера и телефона откуда угодно.

## Откуда данные

Все данные справочника лежат в этом репозитории, в папке `seed\`:

| Файл | Что в нём |
|---|---|
| `seed\codes\*.json` | коды ошибок OBD-II и VAG |
| `seed\articles\*.md` | статьи базы знаний |
| `seed\schemes\*.json` | ссылки на электросхемы и распиновки |
| `seed\parts.json` | запчасти: номера VAG и аналоги |
| `seed\maintenance.json` | регламент ТО |
| `seed\links.json` | полезные ссылки |

Правила наполнения описаны в `seed\README.md`:
- только открытые источники, у каждого факта есть ссылка и дата;
- статус у всего «не проверено»;
- с форумов берётся только пересказ своими словами;
- платные базы (erWin, ELSA, Autodata и т. п.) и их копии не используются;
- моменты затяжки, объёмы, установка ГРМ и регулировки не приводятся: вместо них
  написано «уточнить по официальной документации».

## Как обновляется сайт

Любое изменение в ветке `main` автоматически пересобирает и выкладывает сайт
(GitHub Actions, файл `.github\workflows\pages.yml`). Перед выкладкой прогоняются тесты,
в том числе проверка, что в черновиках нет критичных цифр.

## Посмотреть на своём компьютере

Нужен Node.js 22.13 или новее. Двойной щелчок по `start.bat` (или `npm install`, затем `npm start`)
открывает справочник на `http://localhost:8080`. Собрать сайт в папку `dist\`: `npm run build`.

## Для обслуживания

- `npm test` — тесты: поиск, правила черновиков, страницы, сборка сайта.
- `npm run check-links` — проверка, что все ссылки в черновиках открываются.
  Часть сайтов (в основном drive2.ru) не отвечает автоматическим запросам,
  такие ссылки помечаются «открыть вручную».

## Устройство

```
seed\      данные справочника
src\       страницы (routes), сборка сайта (build.js), загрузка данных (lib\seed.js)
public\    стили, поиск в браузере (js\), токены и иконки Radix UI (radix\, лицензия MIT)
tests\     тесты
```

Оформление — дизайн-система Radix UI: токены Radix Themes, цвета и иконки Radix Icons.
Тема всегда светлая. Боковая панель на компьютере, нижнее меню на телефоне.
