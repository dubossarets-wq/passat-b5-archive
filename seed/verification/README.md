# Проверка наполнения по источникам и по машине владельца

Машина: VW Passat B5, кузов **3B** (дорестайлинг), **2000 модельный год** (10-й знак VIN — Y),
номер шасси вида **3B-Y-3xxxxx** (выше 3B-Y-000001 и выше 3B-X-600000), мотор **ARG**.
Сам VIN и номер шасси в поисковые запросы и внешние сервисы не отправляются — только
сравнение диапазонов из источников у себя.

Файлы `*.json` — JSON-массивы записей:

```json
{
  "kind": "article | code | part | maintenance | diagram",
  "key": "имя файла статьи (seed/articles/…md) | код (P0102) | номер детали как в parts.json (oem) | key позиции регламента | id схемы",
  "status": "confirmed | partial | conflict | unconfirmed",
  "fits": "yes | no | unknown",
  "note": "1–3 предложения по-русски: что сверено, что подтвердилось, что нет, почему подходит/не подходит",
  "checked": ["https://…", "https://…"],
  "date": "2026-11-26"
}
```

- `confirmed` — ключевые факты подтверждены минимум двумя независимыми источниками
  (один из них по возможности официальный: каталог VW Classic Parts, сайт производителя детали, Ross-Tech);
- `partial` — подтверждена часть фактов, остальное — один источник;
- `conflict` — источники противоречат друг другу (что именно — в note);
- `unconfirmed` — подтвердить не удалось.
- `fits` — подходит ли машине владельца (3B, 2000, 3B-Y, ARG): `yes`, `no`, `unknown`.

Проверка не заменяет официальную документацию: критичные цифры по-прежнему только из неё.
