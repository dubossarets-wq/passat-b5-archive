# Черновики для первоначального наполнения архива

При первом запуске приложение загружает эти файлы в базу. Потом всё
редактируется уже в интерфейсе. Файлы здесь остаются как исходник: видно,
что и откуда было взято.

## Правила (обязательны для любого наполнения)

1. **Источники — только открытые.** Публичные справочники (Ross-Tech Wiki и т. п.),
   каталоги производителей запчастей (MANN, MAHLE, Bosch, Gates, ContiTech, INA,
   SKF, NGK и др.), магазины с открытыми карточками товаров, форумы, бортжурналы
   Drive2, статьи.
2. **Платные базы не используем.** Autodata, HaynesPro, Alldata, Mitchell,
   ELSA, erWin и т. п. Не обходим авторизацию, платный доступ и защиту.
3. **Только пересказ своими словами** и ссылка. Чужой текст и картинки не
   копируем. Короткие названия кодов и деталей — это факты, их можно
   передавать близко к оригиналу.
4. **У каждого факта есть источник**: ссылка и дата обращения (`accessed`,
   формат ГГГГ-ММ-ДД). Статус всегда `"unverified"` — «не проверено».
   «Проверено мной» ставит только владелец.
5. **Критичные цифры не пишем вообще.** Это моменты затяжки, установка и
   натяжение ГРМ, допуски и объёмы масла и жидкостей, регулировки, зазоры,
   давления, обороты, углы и проверочные значения датчиков (сопротивления,
   напряжения). Вместо цифры ставим ссылку на параметр из `specs.json`:
   `{{spec:engine_oil_capacity}}`. Приложение покажет либо значение из
   официального документа, либо «уточнить по официальной документации».
   Для значений датчиков пишем «сравнить со значением из официальной
   документации».
6. **У каждого источника помечаем, к чему он относится**: `ARG`, `ADR/APT`
   (родственные моторы, в т. ч. Audi A4 B5), `Passat B5` (кузов в целом),
   `Audi A4 B5`, `OBD-II общее`.
7. **Личных данных владельца здесь нет и быть не должно** (VIN, документы, чеки).

Системы (`system`) — slug из `systems.json`.

## Форматы

### codes/*.json — коды ошибок
Массив объектов:
```json
{
  "code": "P0102",
  "vag": "16486",
  "system": "intake_exhaust",
  "title": "Расходомер воздуха: слишком низкий сигнал",
  "description": "1–3 предложения своими словами: что означает код и когда блок его ставит.",
  "causes": ["частая причина на этом моторе", "..."],
  "checks": ["что проверить, по порядку, без цифр", "..."],
  "applies_to": ["ARG", "ADR/APT", "OBD-II общее"],
  "sources": [
    { "url": "https://...", "title": "Название страницы", "accessed": "2026-11-25", "applies_to": "OBD-II общее", "note": "что взято из источника" }
  ],
  "status": "unverified"
}
```
- `code` — P/B/C/U-код, если он есть; иначе пятизначный VAG-код.
- `vag` — пятизначный код VAG (16xxx/17xxx/18xxx) или `null`.

### articles/*.md — статьи базы знаний
Markdown с YAML-заголовком:
```markdown
---
title: "Охлаждение: типовые проблемы Passat B5 1.8 20V"
system: cooling
applies_to: [ARG, ADR/APT, Passat B5]
status: unverified
sources:
  - url: https://...
    title: Название
    accessed: 2026-11-25
    applies_to: Passat B5
    note: что пересказано
---

Текст своими словами. Ссылки на источники в тексте: [1], [2] — по порядку
списка `sources`. Цифр из правила 5 нет — только `{{spec:...}}`.
```

### links.json — полезные ссылки
```json
[{ "title": "...", "url": "https://...", "category": "official|reference|forum|blog|catalog",
   "description": "своими словами", "applies_to": "Passat B5",
   "checked_at": "2026-11-25", "check_result": "200 OK | что не так" }]
```

### maintenance.json — регламент
```json
[{ "key": "oil", "name": "Моторное масло и масляный фильтр", "system": "lubrication",
   "interval_km": null, "interval_months": null, "status": "unverified",
   "sources": [{ "url": "...", "title": "...", "accessed": "2026-11-25", "applies_to": "...", "note": "..." }],
   "note": "своими словами: откуда интервал и от чего зависит" }]
```
Интервал ставится, только если он прямо указан в открытом источнике по
ссылке. Иначе `null`.

### parts.json — запчасти
```json
[{ "oem": "06A115561B", "name": "Фильтр масляный", "system": "lubrication",
   "maintenance_key": "oil",
   "notes": "от чего зависит применимость: год, PR-код, номер двигателя",
   "analogs": [{ "brand": "MANN-FILTER", "number": "W 719/45", "source_url": "https://..." }],
   "sources": [{ "url": "...", "title": "...", "accessed": "2026-11-25", "applies_to": "ARG", "note": "..." }],
   "status": "unverified" }]
```
Номера в примере показывают только формат, это не данные.
