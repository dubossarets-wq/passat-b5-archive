# Свои схемы и распиновки (seed/diagrams)

Схемы здесь не копируются, а **рисуются приложением** по фактам из открытых источников:
какой разъём, какой контакт, какой сигнал, какого цвета провод, куда он идёт. Чужие
картинки не используются. У каждого факта есть источник; статус всегда `unverified`.

Один файл — один или несколько объектов в JSON-массиве.

## Распиновка разъёма (`type: "pinout"`)

```json
{
  "id": "obd-connector",
  "type": "pinout",
  "title": "Диагностический разъём OBD (16 контактов)",
  "system": "electrical",
  "applies_to": "Passat B5",
  "component": "Диагностический разъём",
  "location": "где стоит разъём — своими словами",
  "layout": { "rows": 2, "cols": 8 },
  "pins": [
    { "pin": "7", "signal": "K-линия диагностики", "wire": "серо-оранжевый", "to": "блоки управления (K-линия)" },
    { "pin": "16", "signal": "+12 В постоянно (клемма 30)", "wire": "", "to": "предохранитель" }
  ],
  "notes": "что важно знать, своими словами",
  "sources": [{ "url": "https://…", "title": "…", "accessed": "2026-11-25", "applies_to": "…", "note": "что взято" }],
  "status": "unverified"
}
```
- `layout` — как контакты расположены на разъёме (ряды × столбцы), если известно; иначе не указывать.
- `pin` — номер контакта как в источнике; `wire` — цвет провода словами по-русски; пустая строка, если неизвестно.
- Номинал напряжения указывать только как обозначение цепи («+12 В», «масса», «клемма 15/30») — это не регулировки.

## Цепь (`type: "circuit"`)

Цепь рисуется как одна или несколько «дорожек» слева направо: от питания через
предохранитель, реле, разъёмы — к потребителю и на массу.

```json
{
  "id": "fuel-pump",
  "type": "circuit",
  "title": "Бензонасос: питание через реле",
  "system": "fuel",
  "applies_to": "ARG",
  "paths": [
    { "label": "Силовая цепь", "nodes": [
      { "name": "Клемма 30 (+АКБ)", "kind": "power" },
      { "name": "Предохранитель S…", "kind": "fuse", "wire": "красный" },
      { "name": "Реле J17", "pin": "30 → 87", "kind": "relay", "wire": "красно-белый" },
      { "name": "Бензонасос G6", "pin": "1 / 4", "kind": "load", "wire": "коричневый" },
      { "name": "Масса", "kind": "ground" }
    ] }
  ],
  "notes": "…",
  "sources": [ … ],
  "status": "unverified"
}
```
- `kind`: `power` (питание), `fuse` (предохранитель), `relay` (реле), `switch` (выключатель),
  `ecu` (блок управления), `connector` (разъём), `sensor` (датчик), `load` (потребитель), `ground` (масса).
- `wire` у узла — цвет провода, который идёт **к следующему** узлу.
- Если номер предохранителя, контакта или цвет неизвестен — так и писать или не указывать. Не выдумывать.
